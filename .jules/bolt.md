## 2025-02-18 - Levenshtein Distance Optimization
**Learning:** The built-in Levenshtein implementation used in this repo's temporal review candidate generation created a new list using `current = [i]` and `current.append(...)`, and used `min(...)` which introduces substantial overhead inside an O(N*M) inner loop. Using pre-allocated lists with `[0] * length`, swapping row references with `previous, current = current, previous`, and replacing `min` with inline ternary comparisons yields a 2.5x performance speedup in Python, which is critical since it runs repeatedly on text sequences extracted from OCR and video processing.
**Action:** When working on string distance metrics or dynamic programming algorithms in hot loops in Python, avoid list `.append()` or `min()`/`max()` and prefer pre-allocated arrays and inline comparisons.
