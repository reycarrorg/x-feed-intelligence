# Gate 3 Residual Risk and Exact Forbidden Supervised Test

Gate 2 does not accept Gate 3 risk. Passive extraction from a visible X page may still violate X's Terms and may expose the account to enforcement even when the implementation is non-automating. Live markup, challenge detection, permission behavior, virtualized cards, account state, accessibility, and resource use remain unverified. The current schema truthfully permits only authored synthetic DOM input and recording input; live DOM provenance requires a separately reviewed schema/source version.

The earliest future supervised comparison is exactly bounded as follows and remains forbidden until the user gives separate authorization after a current policy recheck:

1. Recheck current X Terms, Developer Guidelines, extension/browser policies, and account-enforcement risk from primary sources without signing in through automation. Stop if the risk decision is not explicitly accepted.
2. Version and review a live-DOM source schema; build the exact source revision; inspect every file, permission, CSP, digest, SBOM, and notice; produce a signed/reviewable build. Do not reuse the Gate 2 synthetic manifest or schema label.
3. Create a fresh dedicated browser profile with no imported cookies, history, storage, extensions, proxy, fingerprint modifications, or automation tools. The user signs in ordinarily and handles every credential, MFA, consent, CAPTCHA, challenge, or recovery prompt. The test stops immediately on any challenge, rate limit, unusual activity, parser/permission drift, or unexpected surface.
4. Install only the exact reviewed extension build. The user explicitly grants only the exact live origin, arms it, and starts one session. Granting permission must not start capture.
5. The user manually browses and scrolls a predeclared sample of 100 top-level visible candidate cards for no more than 15 minutes while simultaneously creating a user-controlled screen recording of the same interval. The extension performs no scrolling, click, hover, expansion, playback, refresh, retry, navigation, account action, storage/profile read, or network request.
6. The user explicitly stops and exports once. Import both packets locally, retain provenance differences, and compare one-to-one canonical units. Required results remain DOM precision at least 0.99 and recall at least 0.98; recording precision at least 0.95 and recall at least 0.90; unambiguous relationship and promotion separation exactly 1.00; hard-stop behavior exactly 1.00; forbidden effects, post-stop events/references, secret echoes, and account actions exactly zero.
7. Revoke the exact host permission, uninstall the test build from the dedicated profile, and retain only the user-approved local evidence under the retention contract. Do not publish captures, usernames, post text, profile data, or account identifiers.

Failure of any prerequisite or threshold ends the test without retry, widening permission, alternate account/IP, copied profile, stealth, private endpoint, automated input, or fallback service. This document is a future test protocol, not permission to perform it.
