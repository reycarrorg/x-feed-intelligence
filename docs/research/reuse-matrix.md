# Reuse Matrix

## Disposition definitions

- **Adopt** — preferred component or platform API, subject to an exact-version lock and normal Gate 1 review.
- **Conditional** — useful only if a stated need, license condition, platform constraint, or security gate is satisfied.
- **Reference only** — study architecture, tests, or user experience; do not copy source.
- **Incompatible derivative** — source incorporation would impose a licensing or distribution model that is incompatible with the repository's intended PolyForm Noncommercial distribution.
- **Reject** — outside the product's safety, policy, privacy, or scope boundary even if its software license is permissive.

Repository activity, release, and security-policy observations were checked on September 12, 2026 through the upstream repository and GitHub metadata. A missing published advisory is not evidence that a component is vulnerability-free.

## License compatibility and notice plan

PolyForm Noncommercial 1.0.0 restricts the repository's own source to noncommercial purposes and does not convert third-party code to that license. Every incorporated component must keep its own license, copyright, attribution, source-offer, and relinking obligations.

- MIT, BSD-3-Clause, and Apache-2.0 components are generally compatible with a PolyForm Noncommercial aggregate when their license/copyright texts and Apache notices are preserved. Apache patent and NOTICE obligations still apply.
- Public-domain SQLite imposes no copyright license condition, but provenance and version should still be recorded.
- Apple frameworks are platform SDK dependencies under Apple's agreements, not code to relicense or place in `THIRD_PARTY_NOTICES.md` as open source.
- LGPL FFmpeg is conditional. Running a separately installed executable is the simplest boundary. Bundling FFmpeg requires the exact corresponding source, license notices, build configuration, and LGPL compliance. `--enable-gpl` changes the binary's license; `--enable-nonfree` makes it unredistributable according to FFmpeg's official guidance.[^ffmpeg-license]
- GPL source such as undetected-chromedriver must not be combined into a derivative distributed only under PolyForm Noncommercial. It is unnecessary and independently prohibited by product policy.
- XClipper's package metadata names PolyForm Noncommercial but its inspected tree lacked the actual root license text. Gate 0 therefore records no sufficiently packaged source-reuse grant beyond that assertion.

Gate 1 must create `THIRD_PARTY_NOTICES.md` before the first dependency lands. Each entry needs component, owner, exact version/commit, source URL, license SPDX identifier, full required notice/license location, use in the product, modification status, and binary/source distribution obligations. Lockfiles, generated bundles, model files, trained data, codecs, fonts, and icons are included in the review.
